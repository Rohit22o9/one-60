# Cafe One 60 — Perth CBD Website Prototype

Official website and digital booking portal prototype for **Cafe One 60** (160 Murray Street Mall, Perth WA 6000), created in culinary collaboration with **The Daily Drop**.

## ☕ About Cafe One 60
Founded by sibling duo Shaun and Shabnam in the heart of Perth CBD, Cafe One 60 pairs European café hospitality with Western Australia's finest specialty roasts, artisan breakfast & crêpes, gourmet pressed paninis, and corporate catering.

---

## 🌟 Benchmark Inspirations Incorporated
- **[Copia Perth](https://www.copiaperth.com/):** Day-to-night Perth CBD elegance, commuter-to-lunch workflow, and warm corporate aesthetics.
- **[The Grounds of Alexandria](https://thegrounds.com.au/dine-in/the-grounds-cafe/):** Lush botanical storytelling, artisan bakery and crêpe showcase, and visual gallery.
- **[Basilica Perth & Catering](https://www.basilicaperth.com/catering/):** Corporate office catering packages, boardroom morning tea boxes, and an interactive quote calculator.
- **[La Veen Coffee](https://laveencoffee.com.au/pages/la-veen-cafes):** Specialty single-origin coffee program, 8-hour cold drip, and Grinders Reserve roastery partnership.
- **[Higher Ground Melbourne](https://highergroundmelbourne.com.au/):** Architectural editorial typography, all-day dining menu, and table reservation engine.

---

## 🚀 Key Features
- **Table Reservation System:** Instant reservation flow with date, time, party size, seating area preference (Dining Room, Murray St Mall Alfresco, Espresso Bar), and booking confirmation codes.
- **Interactive All-Day Menu:** Real-time dietary filters (GF, V, VG, DF), category tabs, keyword search, and item customizer modal.
- **Takeaway Bag & Cart Drawer:** Pickup timing selector, order customization, and simulated receipt.
- **Live Corporate Catering Calculator:** Dynamic attendee slider (8 to 150+ guests) with instant price estimates and CBD office delivery inquiry.
- **Commercial Kitchen & Venue Hire (The Daily Drop Synergy):** Dedicated portal for HACCP-certified kitchen shift bookings and private event hire.
- **Location & Trading Times:** Perth CBD transit guide (2-min walk from Perth Station), trading hours, and contact channels.

## 🛠 Tech Stack
- **Framework:** React 19
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Build Tool:** Vite v8

## 💻 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/Rohit22o9/one-60.git
cd one-60

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173` in your browser.

```bash
# Production Build
npm run build
```
